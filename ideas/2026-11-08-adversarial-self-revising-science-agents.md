# 对抗式、自我修正的科学发现 Agent：思维惯性、反证与问题框架重构

> **类型**：Research Idea（未验证）  
> **记录日期**：2026-11-08  
> **阶段**：提出研究问题与可测试架构，尚无本项目实验结果  
> **主题**：LLM cognitive fixation / hypothesis falsification / problem reframing / agent memory / meta-research

## 0. 核心论点

**研究问题**：如何让科研 Agent 不仅在已给定的问题与假设空间中寻找答案，还能怀疑候选假设集合、变量定义、上下文叙事、研究流程以及自己的评判准则？

最初的方案是让「假设支持者」和「假设反证者」两个 Agent 对抗，通过实验决定赢家并在双输时产生第三结论。进一步讨论后发现：**固定正反角色可能本身制造思维固着**。真正需要的是可独立验证的预测、可靠实验、第三假设发现能力、分层证据记忆、以及能对自己的工作机制进行受控修改的 Meta-Research 回路。

**当前设计主张**：固定证据与审计协议，而不固定具体 Agent 数量、角色和上下文策略。把这些架构选择本身作为可检验的假设。

重要边界：这不是一个声称已有突破的新系统。假设对抗、科研多 Agent、自我修改等均有已有工作；差异化贡献必须通过文献对照和公平实验确认。

## 1. 问题：AI 的“思维惯性”包含什么？

不假定 AI 与人类具有相同心理机制；这里讨论的是可观察的行为偏差。

| 现象 | 行为 | 核心风险 |
|---|---|---|
| 联想固着（fixation） | 被误导线索持续牵引 | 难以尝试其他解释 |
| 确认偏误（confirmation bias） | 设计能支持而非推翻自己假设的实验 | 错误理论难以退出 |
| 推理路径依赖 | 自我反思重复早先答案 | 反思不能增加独立搜索 |
| 多 Agent 趋同 | 辩论与历史记忆强化共同偏见 | 多个 Agent 并不等于多种假设 |
| 问题框架固着 | 默认选项、目标、特征和测量方式正确 | “正确答案根本不在候选项里” |
| 上下文惯性 | 把历史解释写成长期事实 | 旧错误不断传播 |
| 元评价固着 | 永远优化某个固定评分器 | 分数改善未必意味着发现能力提高 |

文献线索：*Large Language Models are Fixated by Red Herrings*（NeurIPS 2023）、*Encouraging Divergent Thinking in Large Language Models through Multi-Agent Debate*（EMNLP 2024）、*Failing to Falsify*（2026）、*REFRAME*（EMNLP 2026）、*Spiral of Silence in Large Language Model Agents*（2025）。

**关键区分：** 参数优化、假设空间扩展、问题空间重构是三个不同层次；一个系统可以在第一层表现优秀，却无法完成第三层。

## 2. 人类科学史的启发

### 2.1 光的波粒二象性：第三结论不是折中投票

- 杨氏干涉实验等证据显示波动性，挑战简单经典粒子模型。
- 光电效应的光量子解释（爱因斯坦，1905）及康普顿散射支持粒子式的能量与动量交换。
- 德布罗意物质波与电子衍射表明经典波/经典粒子的二元概念不足。
- 量子理论使用新的数学描述，并非简单宣布“光是水波加小弹珠”。

**工程抽象**：A 解释数据子集一，B 解释数据子集二，并不意味着只能选择 A、B 或平均它们。系统应能改变表示语言和模型类别，并要求新模型在独立数据上提出新的可区分预测。

### 2.2 相对论：挑战原有问题的隐含前提

牛顿时空观与麦克斯韦电磁理论存在张力；迈克耳孙—莫雷实验是重要背景，而不是单次实验直接证明狭义相对论。爱因斯坦重新审视空间、时间和同时性的结构。广义相对论进一步重新描述引力，并接受水星近日点进动、光偏折等检验。

**重要限定**：相对论与量子力学不是一次“二选一”对抗。狭义相对论与量子力学已在量子场论中结合；广义相对论与量子理论的基础统一仍有开放问题。

### 2.3 人类如何“裁决”？

现代对抗式科学合作（例如 2025 年 Nature 对 IIT 与 GNWT 意识理论的检验）更接近我们需要的机制：不同理论支持者共同预注册预测和实验，由相对独立的实验者执行，最后允许“都受到部分支持”“都需修订”“尚不能区分”，不强迫决出冠军。

科学史启发的是 **prediction → discriminating experiment → independent evidence → revised theory**，而不是 Agent 彼此说服。

## 3. 系统的工作原语：可以组合，不能预设必须六个 Agent

| 能力 | 职责 | 输出 |
|---|---|---|
| Hypothesis Generator | 独立提出候选解释 | 假设与条件 |
| Proponent | 为假设构造最强可检验版本 | 明确预测与辅助假设 |
| Falsifier | 主动寻找可能推翻该假设的观测 | 反例与挑战实验 |
| Experiment Designer | 找最大区分力的实验 | 预注册实验方案 |
| Evidence Auditor | 校验数据、分析、泄漏、统计 | 审计报告 |
| Reframer | 检查候选理论共同遗漏的结构 | 新变量、新模型、新问题 |
| Meta Researcher | 检查研究框架本身 | 可比较的框架变更提案 |

这是一组**能力接口**，不是必须部署七个固定 Agent。动态角色、单 Agent + 工具、独立分支等都应参加对照。

固定角色可能造成 Proponent 过度维护立场，Falsifier 为反对而反对。只有受控实验才可以决定是否保留角色划分。

## 4. 实验如何决定胜负与引出第三结论？

对每个候选理论要求它在实验条件 x 下给出可观测预测分布：

```text
H_A -> P(y | x, H_A)
H_B -> P(y | x, H_B)
```

实验设计目标不是让一方看起来正确，而是寻找**双方预测不同、能够可靠测量、成本适当**的实验。预测分布之间的 Jensen–Shannon 散度 / 成本可以作为一种简化启发式；真实设计还要考虑参数不确定性、测量误差、伦理限制及自适应选择偏差。

**可能结论至少六种**：

1. A 的预测获得更强支持：保留 A，继续独立复验。
2. B 获得更强支持：同上。
3. A、B 都与数据相容：寻求更有区分力的实验；也可能不可识别。
4. A、B 都与数据失配：启动 H3 新机制发现。
5. A、B 在不同条件下适用：寻找条件变量与更高阶模型。
6. 数据/实验存在缺陷：暂停判定并修复证据。

可以采用外部可执行的统计评分、预测对数评分、贝叶斯因子或适当的序贯检验。但**LLM 裁判的说服力评分不能替代外部证据**。对于复杂理论，还要区别核心理论问题、辅助假设问题和测量失败（Duhem–Quine 难题）。

### 一个简单的 H3 例子

起初假设 H1 是独立公平硬币（正面率 0.5），H2 是独立有偏硬币（正面率 0.6）。新数据观察到正面约一半，但相邻两次结果改变的比例约 90%。

- H1 预测相邻翻转率 0.5。
- H2 预测相邻翻转率 `2 × 0.6 × 0.4 = 0.48`。
- 新假设 H3 引入时间依赖：平稳边缘仍是 0.5，但 `P(X[t+1] != X[t]) ≈ 0.9`。

H3 的本质是**发现缺失的关系结构**，不是把 0.5 与 0.6 折中。H3 也必须用未来数据检验，不能凭解释旧数据就宣布赢。

## 5. 上下文管理：前一版设计不够好

“为支持者和反证者设置不同上下文，最后共享总结”的做法容易产生两种相反的失败：共享太多导致意见趋同，完全隔离又丢失历史证据。

更严谨的是分离**事实、解释、建议**，采用三层存储：

### L0：原始证据与执行记录

尽可能 append-only、版本化：原始数据、论文出处、实验脚本、随机种子、工具环境、日志、时间戳和哈希。允许添加纠错记录，但不能静默改写历史。

### L1：可争议的假设—证据图

Claim / Hypothesis / Prediction / Experiment / Observation / Interpretation / Counterexample / Scope / Retraction。多个冲突解释可以并存，每个解释须追溯来源；未验证主张不得因被反复总结就升级为事实。

### L2：任务临时上下文

按任务生成视图：完整历史、仅原始证据、反例优先、自适应检索、独立的新鲜视角。记录检索与压缩配方，使结果可复现。

**建议把上下文策略当作实验变量**，而非先验决定哪种最佳。控制总 token、实际证据可见性、运行预算和任务，比较错误传播、独立假设发现率、复验成本。上下文可能本身就是思维固着的主要原因。

## 6. 系统怎样质疑自己的框架？

增加 Meta-Research 回路，但不做“一个 Agent 永远监督另一个 Agent”的无限递归。

### 科学研究回路

```text
问题 + 证据 -> 假设 -> 预测 -> 反例/实验 -> 外部判定
                                          |
                           现有假设共同失配 -> 重构问题 / H3
```

### 元研究回路

```text
研究运行日志 -> 发现研究方法的缺陷
             -> 提议新的上下文/角色/工具/预算/评价方法
             -> 创建框架版本 F_A, F_B...
             -> 相同预算下对照实验
             -> 独立测试集与审计
             -> 保留多个有效分支或回滚
```

**实例**：发现固定支持/反证身份可能导致双方固守立场。让 F_A 继续固定角色，让 F_B 允许动态换边与自由生成新假设，在相同任务与预算下比较。若 B 胜出，还要消融上下文、模型多样性和额外 token，确定真正作用机制。

**自我修正的边界**：可以提出更换评价指标，但不能偷偷改评分器、重写实验记录或反复使用保留集并宣称独立成功。必要的外部审计、权限、安全和证据来源约束应保持独立。现实开放研究不存在一个可以判定一切的“终极评分器”，因此保留多目标与不确定结论。

## 7. 以前是否已有这些框架？

已有相当接近的工作，不能把角色对抗或自修改作为独创新贡献：

| 工作 | 已有部分 | 需要进一步比较的问题 |
|---|---|---|
| POPPER（ICML 2025） | Agent 反证与序贯检验 | 是否扩展问题空间 |
| Co-Scientist（Nature 2026） | 多 Agent 科学假设生成、辩论、筛选 | 如何衡量真正重构问题 |
| 对抗式意识理论合作（Nature 2025） | 多方预注册与中立实验 | 如何自动化整个合作协议 |
| ADAS / Meta Agent Search | 自动搜索 Agent 组织结构 | 评价器固着、跨任务泛化 |
| Darwin Gödel Machine | 自改代码、版本谱系与演化 | 元评价是否独立 |
| Hyperagents（2026） | 改进机制本身可修改 | 是否能可靠修改研究定义 |
| Self-Revising Discovery Systems for Science（2026） | 科学表示和验证规则的改造 | 可复现实验与普遍有效性 |
| Agent Memory Management / Blackboard | 经验复用与共享状态 | 如何避免解释被固化为“事实” |

**可能的研究交叉点**：模型/框架迁移期间的证据保真、问题重构的可操作测量、元系统的独立评价。是否具有研究新颖性仍需进行严格的系统性文献综述。

## 8. MVP：先证明问题值得解决，不要先实现复杂 Agent OS

最小实验世界应具备可重复、隐藏真实机制、允许 Agent 主动设计实验、能够由程序判定结果的属性。建议包含以下类别：

| 环境类型 | 隐藏机制 | 正确能力 |
|---|---|---|
| 模型辨识 | H1 或 H2 真实 | 区分候选假设 |
| 假设集合不全 | H1、H2 都错 | 明确识别失配并提出 H3 |
| 非独立时序 | 有 Markov 依赖 | 发现新的时间关系 |
| 非线性关系 | 交互 / 非线性 | 扩展模型结构 |
| 混杂因子 | 因果不可由表面关联确定 | 寻找干预及识别条件 |
| 测量偏差 | 变量定义错误 | 修正观测模型 |
| 不可识别 | 数据无法区分理论 | 正确认定证据不足 |

### 8.1 对照组

- B0：强单 Agent + 相同研究工具；
- B1：单 Agent + 自反思；
- B2：多 Agent 自由辩论 / 投票；
- B3：支持者 + 反证者 + 冻结预测；
- B4：B3 + 实验设计与独立审计；
- B5：B4 + 独立 Reframer；
- B6：B5 + 受约束的 Meta-Research。

同等模型能力、总 tokens、工具/实验预算、数据可见性和随机种子；分别报告性能与成本。独立 holdout 不得参与框架优化。

### 8.2 主要指标

- 识别“初始假设空间不包含真相”的准确率与误报率；
- H3 在**独立数据**上取得预测改进的比例；
- 发现第三机制所需实验次数、时间和费用；
- 对无法区分假设时的校准与 abstention；
- 反证实验的实际信息量；
- 上下文污染、信息泄漏、选择性报告和伪造证据的比例；
- 元框架在保留任务和跨分布任务上的真实提升。

**重要**：产生更多假设、新颖措辞或更长辩论不等于科学发现。

### 8.3 优先实验

| ID | 命题 | 对照 | 反证条件 |
|---|---|---|---|
| H1 | 反证职责提升假设发现率 | B0/B3 | 同预算无实际改善 |
| H2 | 实验设计比自由辩论更重要 | B2/B4 | 收益仅来自更多实验 |
| H3 | Reframer 提升新机制发现 | B4/B5 | H3 无 holdout 预测增益 |
| H4 | 共享完整历史加重固着 | Full/Evidence | 控制信息后没有负效应 |
| H5 | 动态角色优于固定正反角色 | F_A/F_B | 无独立的跨任务改善 |
| H6 | 元框架演化提升研究能力 | B5/B6 | 只提高优化集而非保留集 |

阶段性路线：先做任务生成器和 B0 基线 → 加冻结预测与反证实验 → 加 Reframer 与 L0/L1/L2 → 最后才允许元框架受控变更。不应在证明基础收益前搭建复杂系统。

## 9. 失败模式和放弃标准

- 多个 Agent 共享同一偏见，形成“伪独立”；
- 反证者为了获胜挑选噪声、无效数据；
- 同一数据被重复用于发现与独立验证；
- 对不可识别问题强行创造第三理论；
- 记忆压缩丢失不确定性与反例；
- 系统修改评分器以“改善成绩”；
- 元优化在固定 benchmark 上过拟合；
- 庞大角色编排的复杂性成本超过收益。

**什么会改变我的判断？** 如果强单 Agent + 高质量实验工具以同预算持续追平或胜过复杂多 Agent；如果加入 Reframer 只提升概念新颖性而非新数据预测；如果上下文隔离不改善固着；如果自修改仅对旧评测集有效，就应删去相应模块或重新定义研究方向。

## 10. 与 Kaggle / 自动研究 Agent 的关系

Kaggle 强队与优秀科研人员的价值并非只有参数搜索，还包括发现目标定义、特征、验证切分、数据生成机制与隐藏泄漏等问题。AI 可能持续优化既有模型却没有问：这个验证方法是否在测错问题？

可把比赛中的“假设 A：提高模型容量”“假设 B：增加特征”进一步提升到“假设 C：现有验证设计无法代表最终任务”。但**不能直接把真实竞赛公开榜反复试探当作独立证据**；需要严格 holdout、审计和反泄漏控制。

此方向与个人长期研究系统设计有关，但本 Idea 不要求立即并入任何现有产品或仓库。

## 11. 开放问题

1. 怎么对“框架重构”做形式化定义？新变量、模型类、测量对象、目标函数变化是否可统一？
2. 跨框架如何保留可追溯的观测证据，避免旧知识被新概念覆盖？
3. 何时应该分裂研究分支、合并理论、停止实验或承认不可识别？
4. L1 知识图谱是否真比可重放日志 + 选择性检索更有效？
5. 如何区分自主结构发现和模型训练中熟悉的题型套路？
6. 外部评价本身有缺陷时，如何修订它而不允许系统自我认证？
7. 什么情况下一个强单 Agent 比多 Agent 更合适？
